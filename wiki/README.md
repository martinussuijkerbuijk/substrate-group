# Substrate Collective — Wiki

Managed by Claude Code. Human team members read here; they go to `raw/` only to verify or quote.

---

## Navigation

| Folder | What's in it | When to use it |
|--------|-------------|----------------|
| `concepts/` | Theoretical building blocks | You need to understand a term or framework |
| `methods/` | Investigative techniques | You're planning or executing an investigation step |
| `sources/` | One-page synthesis per book/paper in `raw/` | You want to know why a source matters before reading it |
| `entities/` | Recurring actors, companies, infrastructure nodes | You're tracking who owns or operates what |
| `patterns/` | Recurring evidence patterns across investigations | You suspect you're seeing something the team has seen before |

Active investigation outputs live in `dossiers/`. The dossier template is at `dossiers/_template/`.

---

## For Claude Code

When a new file appears in `raw/`, create a synthesis note in `wiki/sources/` using the template in `wiki/sources/_template.md`. When a concept appears in three or more sources, create or update a `wiki/concepts/` entry. Cross-link with `[[slug]]` notation using the filename without `.md`.

Do not summarize everything in a source. Synthesize: what does it argue, why does it matter *to this team specifically*, what concepts does it introduce.
